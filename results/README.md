# Research Results Assets

This folder contains figures extracted from the project's uploaded EDA report and IEEE-style conference paper.

## EDA figures
The `eda/` folder contains signal plots and analysis figures from the EDA report:
- Dataset distributions
- Voltage and current signals
- Correlation and magnitude analysis
- FFT and spectrogram
- Wavelet scalogram and fault energy
- Symmetrical components and three-phase trajectories

## Training figures
The `training/` folder contains training/validation accuracy and loss figures for:
- 1D-CNN
- BiLSTM
- CNN-BiLSTM

## Evaluation figures
The `evaluation/` folder contains the BiLSTM confusion matrix reported in the paper.

## Source note
These are extracted figures from the project's supplied reports, not newly generated plots. Refer to `docs/eda_report.pdf` and `paper/ieee_conference_paper.pdf` for the complete context and methodology.
